# 前端优化计划 v1.0

## Context

用户已确认 schema_confirm.md 作为前后端数据契约，前端需要基于此重构以实现：
1. 用户路径优化（全链路闭环）
2. React Router 启用（URL 驱动导航）
3. Zustand 引入（全局状态管理）
4. 前后端真实数据对接

**新增需求**：在路径最前面加用户建档功能（老用户账号密码登录 / 新用户注册）

---

## 一、用户路径重构 + 交互优化

### 1.1 当前问题

```
Home(setTimeout 5秒假AI) → Info(表单) → Planning(静态demo) → Map(伪坐标) → Emergency(硬编码)
```

| 问题 | 影响 |
|------|------|
| Home 页假 5 秒 `setTimeout` | 用户体验割裂，以为在等 AI |
| 状态驱动导航，URL 不变 | 浏览器后退无效，无法分享链接 |
| 页面间无数据传递 | 每个页面都是独立静态 demo |
| 跳转逻辑不连贯 | Planning → Map → Emergency 无清晰入口 |
| 无用户身份识别 | 无法预加载老用户资料 |

```
    │       └── ⚠️ 应急模式（快速求助）
    │
    └── 行程已结束（当前日期 > 行程结束日期）
            │
            ▼
        HomePage  ← 显示"行程已完成"提示
```

**行程状态自动更新逻辑（基于日期）：**
```
当前日期 < 行程开始日期 → status: "pending"（待出行）
行程开始日期 ≤ 当前日期 ≤ 行程结束日期 → status: "ongoing"（进行中）
当前日期 > 行程结束日期 → status: "completed"（已完成）
```
